How it works

Three steps, and you're typing Marathi everywhere on your Mac.

  1. Install AksharaIME

    A normal macOS installer. It adds AksharaIME as a selectable input source in System Settings — nothing else changes.

  2. Switch to it from the input menu

    Pick AksharaIME from the menu bar or with your usual input-switch shortcut, same as switching to any other keyboard layout.

  3. Type phonetically, anywhere

    TextEdit, Notes, Word, your browser, Slack — type mahArAShTra and get महाराष्ट्र, right in place, as you type.

Setting up after you buy

This is an early-access build, so a couple of one-time steps aren't automated yet — here's exactly what to do.

  1. Download and run the installer

    It isn't notarized by Apple yet, so macOS will likely block it the first time — this is expected, not a sign something's wrong. Click Done on the warning, then go to System Settings → Privacy & Security, scroll down, and click Open Anyway next to the AksharaIME message. You'll be asked to confirm once more.

  2. Log out and back in (or restart)

    This is a one-time macOS requirement, not optional — AksharaIME won't be selectable as a keyboard until you do this once after installing.

  3. Add AksharaIME in System Settings

    Go to System Settings → Keyboard → Input Sources → Edit… → +, find AksharaIME under English (or search "akshara"), and add it.

  4. Sign in and activate this Mac

    Open AksharaIME Companion from your Applications folder, sign in with the email you used to buy, and activate this Mac. You're set — switch to AksharaIME from the input menu and start typing.

Does it work offline?
