# AksharaIME marketing site

Static single-page site (`index.html`, no build step). Deployed via GitHub Pages from
`main` at https://om-chavan501.github.io/akshara-ime-website/

This is deliberately a SEPARATE repo from the product source (which lives privately
elsewhere) -- keeps proprietary code out of a public repo needed for free Pages hosting.

## Workflow

Changes go through a feature branch + PR, reviewed and merged by the repo owner --
not pushed straight to `main`. (`main` -> live site immediately on merge, so this is the
actual review gate before anything public changes.)
