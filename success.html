What to do next

  1. Download and run the installer.
    Download AksharaIME for Mac
  2. Get past the security warning. AksharaIME isn't notarized by Apple yet, so macOS will say it can't verify the developer. Click Done, then open System Settings → Privacy & Security, scroll down, and click Open Anyway.
  3. Log out and back in (or restart). macOS only picks up newly installed input methods after a login cycle.
  4. Add the input source. System Settings → Keyboard → Input Sources → +, then find AksharaIME under English.
  5. Open AksharaIME Companion and sign in with the email shown above. You'll get a 6-digit code by email. Then click Activate this Mac.
  6. Start typing. Switch to AksharaIME in the menu bar and type namaskaara — you should get नमस्कार.
